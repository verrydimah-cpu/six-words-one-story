A complete story in exactly six words: "Mother's recipe worked. Father finally cried." The mother is gone and her recipe is what remains of her; cooked again, it does what words could not — it lets a father who held himself together finally grieve. The program in `main.ts` (Node 22, standard library only) writes that single line, byte-identically on every run, to `entry.txt` in the output directory (`/output`, or `$MAKEFUN_OUTPUT_DIR` anywhere else), clearing only the directory's contents first.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
